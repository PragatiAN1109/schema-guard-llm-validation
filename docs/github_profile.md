# GitHub Profile — SchemaGuard

## Repository Description (1 line)

Semantic compliance and drift detection layer for LLM-generated structured JSON outputs.

## Portfolio Tagline

SchemaGuard — catches the logical errors that schema validation misses when LLMs generate structured data.

## Highlights

- **Semantic validation engine** with 10 cross-field rules across healthcare and finance domains — catches contradictions that pass schema checks
- **Drift detection** monitors LLM output distributions over time using z-score, PSI, and null-rate tracking
- **Confidence scoring + decision routing** assigns 0–1 scores and routes records to trusted / flagged / quarantined with audit trails
- **Full-stack delivery** — FastAPI REST API, Streamlit demo UI, evaluation pipeline with 100% seed accuracy

## Tech Stack
