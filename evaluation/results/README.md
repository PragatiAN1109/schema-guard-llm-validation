# evaluation/results/

Evaluation outputs generated by `evaluation/generate_full_metrics.py`.

| File | Description |
|------|-------------|
| `full_metrics_report.json` | Complete metrics report — classification (P/R/F1), confidence gaps, rule violation counts, latency percentiles, drift baseline list |
| `metrics_table.csv` | 45-row tabular form of all metrics (pivot-ready for Excel or pandas) |
| `evaluation_summary.json` | Legacy summary from initial evaluation run (16 seed records) |
| `healthcare_eval_results.json` | Per-record results for all 8 healthcare seed records |
| `finance_eval_results.json` | Per-record results for all 8 finance seed records |

## Regenerate

```bash
cd schema-guard-llm-validation
python3 evaluation/generate_full_metrics.py
```

Outputs 12 plots to `outputs/plots/` and refreshes both JSON and CSV files.
