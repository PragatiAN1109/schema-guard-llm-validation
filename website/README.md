# website/

Project website for SchemaGuard. Single self-contained HTML file with embedded CSS.

## Viewing

Open `index.html` in any browser — no build step, no dependencies.

2. Problem statement (3 example cards)
3. Validation pipeline flow + decision cards
4. Semantic rules tables (both domains)
5. Drift detection signals
6. Evaluation results + metrics
7. API endpoints + sample response
8. Prompt engineering approach
9. Tech stack + project structure
10. Quick start commands
